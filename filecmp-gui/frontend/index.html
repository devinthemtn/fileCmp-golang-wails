Help — File Compare

Getting started

Pick Files / Directories to compare two paths, or Git to compare two refs (type one, or pick a branch, tag or recent commit from the dropdown) (leave the right ref blank to compare against the working tree). Press Compare or Enter, then choose a file from the list on the left.

External tools

Editor
$FILECMP_EDITOR, then $VISUAL, then $EDITOR, then the OS default
Diff / merge tool
git config diff.tool / merge.tool (e.g. meld, kdiff3)
Resolve conflict
Shown for conflicted files in Git mode; runs git mergetool

Config files

File Compare has no config file of its own. Tool choices are read from git config:

Global
~/.gitconfig or ~/.config/git/config
Windows: %USERPROFILE%\.gitconfig
Per repository
<repo>/.git/config (overrides global)
Keys
diff.guitool (GUI only), diff.tool, merge.tool, difftool.<name>.cmd
Editor vars
Set in your shell profile (~/.bashrc, ~/.zshrc, …) — a desktop launcher may not see them
